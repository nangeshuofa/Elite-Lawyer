> **把重复劳动交给 AI，把判断和决策留给律师。**

一个跑在 AI 工作区里的律师专属技能（Skill）：案件管理、文书生成、法律检索、合同审核、时效预警、客户管理——全部以**文件化状态**持久化，跨会话不忘事；内置**六大红线**与**输出可信度分级**，法律输出的准确性有护栏。

## ✨ 为什么是 Elite-Lawyer

| 律师的日常痛点 | 本技能的解法 |
|---|---|
| 时效漏一个就是执业事故 | 全局时效总表 + 多级预警（7/3/1天+当天）+ 漏时效应急 SOP |
| 文书从空白页开始写 | 触发词直达工作流，模板+法条+质检链一次成型 |
| 法条案例凭记忆引用 | ✅/⚠️/❓ 三级可信度强制标注，没核验的绝不装成已核验 |
| 知识散落在聊天记录里 | L0 存储层：案件/时效/知识全部落盘，越用越聪明 |
| AI 胡说八道没有刹车 | 六大红线 + 空库不编造 + 不确定必说 ❓ |

## 🏗 架构

DA 五层（稳定性 > 可维护性 > 可扩展性）：

```
┌──────────────────────────────────────────────────┐
│ L4 知识库层   法规库 / 案例库 / 模板库 / 裁判规则   │  知识弹药（可积累）
├──────────────────────────────────────────────────┤
│ L3 模块层     案件·文书·检索·合同·客户·日程        │  触发路由 → 执行 → 输出
├──────────────────────────────────────────────────┤
│ L2 机制层     流程引擎·时效预警·知识发现·质量控制   │  纯规则（Single Source of Truth）
├──────────────────────────────────────────────────┤
│ L1 内核层     角色定位·执业原则·全局优先级          │  身份与红线
├──────────────────────────────────────────────────┤
│ L0 存储层     .state/ 案件·时效·配置 + 存储契约     │  持久化根基（schema v2）
└──────────────────────────────────────────────────┘
依赖方向：L3 → L2 → L1 → L0，L4 被读写；禁止反向与循环依赖。
```

- **触发词路由表**是技能唯一的路由来源（`SKILL.md`）
- **每条规则只在一处定义**，其余位置引用（架构约束强制）
- 详细铁律见 [`L0_存储层/架构约束.md`](L0_存储层/架构约束.md)

## ⚡ 快速开始

> 适用环境：支持加载 Skill 目录的 AI 工作区（如腾讯 ima.copilot），或任何能读写本地文件的 Agent 运行时。

**Step 1 — 放置技能**：将本目录放入工作区的 `skills/` 下

**Step 2 — 初始化配置**：编辑 `.state/config.json`（或在对话中直接说"设置我的律所为 XX"）：

```json
{
  "lawyer_name": "你的名字",
  "firm_name": "XX律师事务所",
  "default_court": "常用管辖法院"
}
```

⚠️ 个人执业证号等敏感信息请仅在私有副本中填写，勿提交回公共仓库。

**Step 3 — 说第一句话**：

```
新建案件：张某诉某医院医疗损害责任纠纷，我是原告代理律师
→ 自动建档 → 自动识别时效 → 主动建议下一步（检索法条？生成起诉状？）
```

**Step 4 — 冒烟验证**：对照 [`examples/冒烟测试对话.md`](examples/冒烟测试对话.md) 的 5 个用例跑一遍（含验收标准表）。

## 🛡 护栏设计（法律技能的自我修养）

1. **六大红线**：不泄露秘密 / 不伪造依据 / 不承诺结果 / 不私自接案收费 / 不越权 / 不隐瞒不利信息
2. **可信度分级**：法条与案例强制标注 ✅已核验 / ⚠️未核验 / ❓待确认；空库只答"未检索到"，严禁编造
3. **集成边界**：发送消息、日历同步、法条联网核验等动作明确标注 ⚙️ 属平台/人工执行，AI 不假装自己能做
4. **分工铁律**：AI 做信息整理与初稿，律师做事实判断与最终决策——所有输出定位为"律师复核前的半成品"
