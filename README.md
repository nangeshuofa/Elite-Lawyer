# Elite-Lawyer 精英律师数字助手（公开版）

> 作者：楠哥说法 ｜ 版本：V7.7.0（公开版） ｜ 协议：GPL-3.0

面向执业律师的数字助手技能包，以案件为核心，覆盖文书生成、法律检索、合同审核、法律意见、伦理审查、客户与日程管理、时效预警、诉讼可视化、品牌宣传与领导力等全流程。

本仓库发布的是**公开版**：已移除原使用者的个人化内容（姓名、律所、客户与案件标识）、第三方个人信息与机构标识，可直接安装使用；个人化信息在你的环境中自动回填。

## 仓库内容

| 路径 | 说明 |
|---|---|
| `elite-lawyer/` | 技能本体目录（放入技能根即可被加载） |
| `elite-lawyer-public-v7.7.0.skill` | 技能打包文件（本质是 ZIP，`SKILL.md` 位于压缩包根目录） |
| `elite-lawyer-public-v7.7.0-extras.zip` | 可选加装包：14 个常识/地域分片 |
| `LICENSE` | GPL-3.0 全文 |

## 安装

1. 下载 `elite-lawyer-public-v7.7.0.skill` 并解包（也可直接使用 `elite-lawyer/` 目录）
2. 放到技能根目录下，使路径为 `<技能根>/elite-lawyer/SKILL.md`
   - 技能根因平台而异，常见为用户级 `~/.dsh/skills` 或项目级 `<项目>/.dsh/skills`
3. 自检：`python3 elite-lawyer/tools/check.py elite-lawyer` —— 应为 **11 项 PASS、exit 0**

### 可选加装包

`elite-lawyer-public-v7.7.0-extras.zip` 内含 7 个常识分片（民族/历史/哲学/社会学/政治学/音乐/艺术）与 7 个地域专题（成都/雅安/宜宾/北京/上海/广州/济宁）。

解包后放入 `elite-lawyer/L4_知识库层/通识库/`，并在 `elite-lawyer/L4_知识库层/index.md` 的「通识知识库」分片表登记，即可恢复完整知识面。

未安装时技能的行为约定：命中相关常识需求须明确告知「本包未收录」或联网核实权威来源后作答，**不臆造**。

## 首次配置

编辑 `elite-lawyer/.state/config.json`，或在对话中说「设置我的律所为XX」「我的执业证号是XX」，由 `auto_profile` 机制自动回填。`lawyer_name` 等字段留空不阻塞任何功能。

## 架构

```
L0 存储层 → L1 内核层 → L2 机制层 → L3 模块层 → L4 知识库层
 状态持久化   身份原则   质控·分流   功能模块    知识弹药
```

- **L1 内核层**：角色定位与分工边界、执业原则（含六大红线）、元认知四步闭环
- **L2 机制层**（8 个）：案件流程引擎、时效预警、知识发现、质量控制、核准校验、边缘计算、真实世界接口、人脸识别
- **L3 模块层**（14 个，M01–M14）：案件管理、文书生成、法律检索、合同审核、客户管理、日程排期与待办、诉讼可视化、脑器交互、法律意见、伦理审查、财务管理、后勤支持、品牌宣传、领导力
- **L4 知识库层**：法规库、案例库、模板库、裁判规则、执业规范、前沿领域、通识库

## 主要特性

- **输出可信度强制分级**：涉及法条/案例的输出必须标 ✅已核验 / ⚠️未核验 / ❓待确认；检索无结果时明确告知，**不编造法条或案号**
- **集成边界声明**：明确区分「AI 可直接执行」与「需平台/人工执行 ⚙️」，不假设平台能力
- **异常分支与降级**：信息不全、检索无果、工具不可用等情况按既定分支处理，不静默失败
- **一键体检**：`tools/check.py` 纯标准库离线自检 9 项（四方版本一致性、索引引用完整性、模块注册三向对账、L4 分片反向登记、工具痕迹扫描等）
- **向后兼容承诺**：`schema_version: 2`，旧版状态数据在新版下自动兼容
