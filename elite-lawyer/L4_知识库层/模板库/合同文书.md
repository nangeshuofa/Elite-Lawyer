# 模板库 · 合同文书分片

> 按 `index.md` 检索协议访问。本文件收录合同类文书模板。
> `【】` 内为需填充内容。模板是骨架不是成品：AI 生成时必须结合交易背景补全商务条款，并提示律师审查风险点。模板使用原则同诉讼文书分片：格式可套用，事实与风险判断必须律师把关。

## 模板一：劳动合同（通用骨架）

> 必备条款对齐《劳动合同法》第17条。缺必备条款可能面临行政责令改正及赔偿责任。

```
劳动合同

用人单位（甲方）：【名称】【统一社会信用代码】【住所】【法定代表人】
劳动者（乙方）：【姓名】【身份证号】【住址】【联系方式】

一、合同期限
固定期限：自【年月日】起至【年月日】止。
（或：无固定期限自【年月日】起；或以完成一定工作任务为期限）

二、试用期（不得超过法定上限：合同期3个月-1年≤1个月；1-3年≤2个月；3年以上/无固定期限≤6个月；同一单位只能约定一次）
试用期自【年月日】起至【年月日】止，试用期工资【金额/比例，不低于约定工资80%且不低于当地最低工资】。

三、工作内容和工作地点
岗位：【岗位名称】，工作内容：【职责概述】。
工作地点：【地点】。因经营需要变更工作地点的，【协商机制】。

四、工作时间和休息休假
执行【标准工时/综合计算工时/不定时】工时制度。
（实行特殊工时制须注明已经劳动行政部门审批）

五、劳动报酬
工资标准：【金额】/月，于每月【日】支付。加班工资按法律规定计算。

六、社会保险
甲方依法为乙方缴纳社会保险费。【补充商业保险：方案】

七、劳动保护、劳动条件和职业危害防护
【岗位职业危害告知+防护措施】

八、专项培训与服务期（如有）
甲方提供专项培训费用进行专业技术培训的，约定服务期【年】，违约金不超过培训费用，且不超过服务期尚未履行部分应分摊的培训费用。

九、保密与竞业限制（如有）
竞业限制范围、地域、期限（不超过2年）及经济补偿标准：【按月补偿标准】。

十、合同的解除、终止与经济补偿
按《劳动合同法》及双方约定执行。

十一、争议解决
因履行本合同发生争议的，可向劳动争议仲裁委员会申请仲裁。

甲方（盖章）/ 乙方（签字）：
日期：
```

> **风险提示（生成时必须附带）**：①违约金只能约定服务期（第22条）和竞业限制（第23条）两种情形，其他约定无效（第25条）；②竞业限制须按月支付经济补偿，未支付超3个月劳动者可解除；③规章制度须民主程序制定并公示，否则不能作为解除依据。

## 模板二：服务合同（通用骨架）

```
服务合同

委托方（甲方）：【名称/身份证号】【住所】【联系方式】
服务方（乙方）：【名称】【资质/许可编号】【住所】【联系方式】

一、服务内容与标准
【服务事项逐项列明；验收标准量化：范围、深度、交付物、时限】
（涉及许可经营事项的，写明资质要求与证照附表）

二、服务期限与进度
自【年月日】至【年月日】；里程碑：【节点+对应交付物】。

三、服务费用与支付
总价【金额】（含/不含税，税率【】）；
支付节点：【首付比例+进度款+验收款+质保金比例】；
支付方式：【对公账户信息】。

四、双方权利义务
甲方：【配合义务、资料提供、决策确认时限】。
乙方：【人员资质承诺、转包禁止、保密义务、安全责任】。

五、知识产权与成果归属
【交付成果归属、背景知识产权、甲方资料的返还与销毁】

六、验收
验收标准与程序：【书面验收单】；逾期未提异议视为验收通过的条款：【建议明确】。

七、违约责任
迟延交付：每逾期一日按合同总价【比例】支付违约金；
服务质量不符：修复/重做/减价的选择权；
根本违约解除权：【约定解除情形】。

八、保密条款
【范围、期限（可约定不因合同终止而失效）、违约责任】

九、不可抗力
发生不可抗力的一方应在【日】内通知对方并提供证明。

十、争议解决
协商不成：【选定向合同履行地/约定地法院起诉，或约定仲裁机构（二选一写清）】。

甲方（盖章）/ 乙方（盖章）：
日期：
```

> **风险提示**：①管辖条款避免"或裁或诉"（无效）；②付款节点与交付里程碑绑定；③服务方涉及医疗、检测等特许行业的核对许可证有效期。

## 模板三：保密协议（通用骨架）

```
保密协议

披露方（甲方）：【名称】【住所】
接收方（乙方）：【名称/姓名】【住所】

一、保密信息定义
包括但不限于：【技术信息：方案、数据、源代码；经营信息：客户名单、定价、财务；医疗场景：患者信息、临床数据】。
例外：已公开信息、接收前已合法持有、独立开发、有权机关依法要求披露。

二、保密义务
未经书面许可不得向第三方披露、不得用于本协议目的之外用途；按"最小必要"范围知悉；到期或终止时返还或销毁。

三、涉个人信息与数据的特别约定（医疗/互联网场景必选）
处理个人信息遵守《个人信息保护法》，敏感个人信息（含健康医疗数据）取得单独同意；数据不得出境或传输至【范围】外；发生泄露事件【小时】内通知甲方。

四、期限
自签署之日起生效，保密义务期限【年/长期】，不因合作终止而免除。

五、违约责任
违反本协议支付违约金【金额/计算方式】；造成损失超过违约金的，按实际损失赔偿；同时承担维权合理费用（律师费、公证费等）。

六、争议解决
【法院管辖或仲裁，二选一】

甲方（盖章）/ 乙方（签字或盖章）：
日期：
```

> **风险提示**：员工场景下保密协议与竞业限制协议功能不同——保密义务不需要额外支付对价，竞业限制必须支付月补偿，二者不可混用；患者隐私泄露同时触发民法典第1226条侵权责任与行政责任，医疗场景优先落实第三条。
