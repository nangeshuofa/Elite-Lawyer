# 法规库 · 民商法分片

> 按 `index.md` 检索协议访问。本文件收录民法典及公司、担保等民商领域高频条款，按"条款+内容+适用场景"表格沉淀。

## 民法典总则编 — 诉讼时效与行为能力

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第143条 | 民事法律行为有效要件（行为能力+意思表示真实+不违法不违公序良俗） | 合同效力判断 |
| 第145条 | 限制民事行为能力人实施的纯获利益或与其年龄、智力相适应的行为有效 | 未成年人交易效力 |
| 第188条 | 普通诉讼时效3年，自权利人知道或应当知道权利受损及义务人之日起算；最长20年 | 时效抗辩与起诉前自查 |
| 第194条 | 诉讼时效中止（不可抗力、被控制人身自由、继承未定等） | 时效届满前补救 |
| 第195条 | 诉讼时效中断（请求履行、起诉/仲裁、义务人同意履行），中断后重新起算 | 催款留痕策略 |
| 第196条 | 不适用诉讼时效的请求权（停止侵害、排除妨碍、返还物权、支付抚养费赡养费等） | 时效抗辩应对 |

## 民法典合同编 — 通则与违约

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第490条 | 合同自签名、盖章或按指印时成立 | 合同成立争议 |
| 第502条 | 依法成立的合同自成立时生效；需批准登记的依其规定 | 合同生效判断 |
| 第509条 | 全面履行与诚信履行原则 | 违约认定基础 |
| 第511条 | 约定不明的补充规则（质量/价款/地点/期限/费用负担） | 合同漏洞填补 |
| 第563条 | 法定解除五情形（不可抗力致目的落空、预期违约、迟延催告后仍不履行等） | 合同解除权判断 |
| 第577条 | 违约责任形态：继续履行、采取补救措施、赔偿损失 | 违约索赔 |
| 第580条 | 非金钱债务履行的除外情形（法律/事实不能、履行费用过高、合理期限内未请求） | 继续履行可行性 |
| 第584条 | 损失赔偿范围含可得利益，以违约方订立时预见或应预见的损失为限 | 损失主张与抗辩 |
| 第585条 | 违约金：过分高于损失的可请求适当减少（以实际损失为基础综合衡量，参见合同编通则司法解释 法释〔2023〕13号） | 违约金调减攻防 |
| 第586-587条 | 定金不超过主合同标的额20%；定金罚则（给付方违约无权返还/收受方违约双倍返还） | 定金担保与索赔 |
| 第590条 | 不可抗力部分或全部免责，应及时通知并提供证明 | 疫情等免责抗辩 |

## 民法典 — 担保（重大变化提示）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第388条 | 担保合同包括抵押、质押及其他具有担保功能的合同 | 担保效力认定 |
| 第686条 | 保证方式没有约定或约定不明确的，按**一般保证**承担（重大变化：与原担保法相反） | 保证责任形态判断 |
| 第688条 | 连带责任保证需明确约定；连带保证人无先诉抗辩权 | 保证人追责路径 |
| 第692条 | 保证期间没有约定/约定不明的，为主债务履行期限届满之日起**6个月** | 保证期间计算与除权 |

## 民法典侵权责任编 — 通用规则

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第1165条 | 过错责任原则（过错侵权的一般条款） | 一般侵权归责 |
| 第1166条 | 无过错责任以法律规定为限 | 归责原则选择 |
| 第1173条 | 过失相抵：被侵权人对损害发生有过错的可减轻侵权人责任 | 责任比例划分 |
| 第1179条 | 人身损害赔偿项目：医疗费、护理费、误工费、残疾赔偿金、死亡赔偿金等 | 损失清单编制 |
| 第1183条 | 精神损害赔偿：造成严重精神损害的可主张 | 精神抚慰金主张 |
| 第1188条 | 监护人责任（无/限制民事行为能力人致害） | 未成年人与特殊人群侵权 |
| 第1198条 | 经营场所/公共场所安全保障义务 | 场所责任纠纷 |

## 公司法（2023修订，2024年7月1日施行）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
