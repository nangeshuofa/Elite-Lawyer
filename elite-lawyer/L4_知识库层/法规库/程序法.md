# 法规库 · 程序法分片

> 民事诉讼法、行政诉讼法、仲裁法等程序性法律高频条款。**条款号已按现行版本核校（2026-09-05）**：民事诉讼法为 2023 修正版（2024年1月1日施行），条款号经最高人民法院公报刊载全文核对。

## 民事诉讼法（2023修正）— 核心条款（高频速查）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第22条 | 一般地域管辖（被告住所地） | 确定管辖法院 |
| 第24条 | 合同纠纷管辖（被告住所地或合同履行地） | 合同纠纷立案 |
| 第29条 | 侵权纠纷管辖（侵权行为地或被告住所地） | 侵权纠纷立案 |
| 第35条 | 协议管辖（与争议有实际联系的地点，不得违反级别管辖和专属管辖） | 合同约定管辖审查 |
| 第67条 | 当事人对自己提出的主张有责任提供证据（谁主张谁举证） | 举证责任分配 |
| 第68条 | 当事人对自己提出的主张应当及时提供证据；逾期举证的说明理由，理由不成立的可不予采纳或采纳但予以训诫、罚款 | 举证期限与逾期举证 |
| 第86条 | 期间顺延：因不可抗拒的事由或其他正当理由耽误期限的，在障碍消除后10日内可申请顺延 | 逾期补救 |
| 第165条 | 小额诉讼：简单金钱给付案件，标的额为各省上年度就业人员年平均工资50%以下的，一审终审；50%以上2倍以下可双方约定适用 | 程序选择与上诉预期管理 |
| 第171条 | 上诉期限：不服一审判决15日、不服一审裁定10日，自判决/裁定书送达之日起算 | 上诉期（不变期间） |
| 第216条 | 申请再审：应在判决、裁定发生法律效力后6个月内提出；特定情形自知道或应当知道之日起6个月 | 再审时效 |
| 第246条 | 申请执行期限2年，适用诉讼时效中止、中断规定 | 执行时效管理 |

## 行政诉讼法（2017修正）— 核心条款

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第20条 | 不动产案件专属管辖（不动产所在地法院） | 行政管辖确定 |
| 第44条 | 复议与诉讼的选择：可直接起诉；法律、法规规定应当先申请复议的依其规定 | 救济路径判断 |
| 第46条 | 起诉期限：直接起诉的6个月（自知道作出行政行为之日起）；不动产案件最长保护20年、其他案件5年 | 行政起诉时效 |
| 第47条 | 不履行法定职责：申请履职后2个月内不履行的可起诉；紧急情况不受时限限制 | 履责之诉 |

## 仲裁法（2017修正）— 核心条款

| 条款 | 内容 | 适用场景 |
|------|------|----------|
