# 法规库 · 医事法分片

> 按 `index.md` 检索协议访问。本文件收录医疗损害、医师执业、医疗纠纷处理等医事领域高频条款。医疗领域为本技能核心赛道，优先维护。

## 民法典侵权责任编第六章 — 医疗损害责任（第1218-1228条 全章速查）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第1218条 | 医疗损害一般过错责任：医疗机构或其医务人员有过错的，由医疗机构承担赔偿责任 | 归责原则判断 |
| 第1219条 | 说明义务与知情同意：病情+医疗措施应说明；手术/特殊检查/特殊治疗须取得明确同意；不能或不宜向患者说明的向近亲属说明；未尽义务致损应赔偿 | 知情同意书瑕疵案件 |
| 第1220条 | 紧急救治：抢救生命垂危患者等紧急情况，不能取得患者或近亲属意见的，经医疗机构负责人或授权负责人批准可立即实施 | 紧急手术签字争议 |
| 第1221条 | 诊疗义务标准：未尽到与当时医疗水平相应的诊疗义务，造成损害应赔偿 | 过错认定（注意"当时医疗水平"地域/时限因素） |
| 第1222条 | 过错推定三情形：违反法律法规规章及诊疗规范；隐匿或拒绝提供病历；遗失、伪造、篡改或违法销毁病历 | 病历瑕疵案件攻防 |
| 第1223条 | 药品/消毒产品/医疗器械缺陷或不合格血液输入：患者可向生产者或医疗机构请求赔偿；医疗机构赔偿后有权向负有责任的生产者等追偿 | 医疗产品责任 |
| 第1224条 | 医疗机构免责三情形：患者或近亲属不配合诊疗（医方也有过错的相应担责）；紧急情况下已尽合理诊疗义务；限于当时医疗水平难以诊疗 | 医方抗辩 |
| 第1225条 | 病历保管与查阅：医疗机构及其医务人员应按规定填写并妥善保管病历；患者要求查阅、复制的，医疗机构应及时提供 | 病历复制权主张 |
| 第1226条 | 隐私与个人信息保密：泄露隐私或未经同意公开病历资料应担责 | 泄密侵权 |
| 第1227条 | 禁止不必要检查 | 过度医疗主张 |
| 第1228条 | 医疗机构及医务人员合法权益受法律保护；干扰医疗秩序、妨害医务人员工作生活的依法承担法律责任 | 医闹应对（医院侧顾问高频） |

## 医师法（2022年3月1日施行）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第13条 | 医师经注册后，在医疗卫生机构中按注册的执业地点、执业类别、执业范围执业 | 执业资质审查 |
| 第23条 | 医师执业义务：遵循临床诊疗指南、合理诊疗、如实告知病情和医疗措施等 | 过错认定参照 |
| 第25条 | 医师如实签署医学文书，不得隐匿、伪造、篡改或销毁病历 | 病历瑕疵案件 |
| 第27条 | 对危急患者，医师应采取紧急措施进行诊治，不得拒绝急救处置 | 急救义务审查 |
| 第29条 | 超说明书用药：在尚无有效或者更好治疗手段等特殊情况下，取得患者明确知情同意后，可以采用药品说明书中未明确但具有循证医学证据的药品用法 | 超说明书用药合规与过错边界 |
| 第55条 | 违法执业的法律责任（警告、暂停执业、吊销证书等） | 行政责任与执业风险评估 |

## 医疗纠纷预防和处理条例（国务院令第701号，2018年10月1日施行）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第13条 | 手术、特殊检查、特殊治疗的知情同意：需开列清单并取得书面同意；紧急情况下不能取得患者或近亲属意见的，按民法典第1220条处理 | 告知义务合规审查 |
| 第16条 | 患者有权复制全部病历资料（含住院志、医嘱单、检验报告、手术及麻醉记录、护理记录、医疗费用等） | 病历复制权主张 |
| 第22条 | 病历封存：发生医疗纠纷需要封存、启封病历的，应在医患双方在场情况下进行；封存的病历可以是复制件 | 证据固定动作（第一时间） |
| 第26条 | 尸检：患者死亡，医患双方对死因有异议的，应当在患者死亡后48小时内进行尸检；具备遗体冻存条件的可延长至7日 | 死因争议案件时限 |
| 第40条区域 | 医疗损害鉴定：医学会或司法鉴定机构接受委托进行鉴定；鉴定意见是责任划分核心证据 | 鉴定启动与质证 |

> 赔偿争议解决途径（条例明确）：医患双方自愿协商 → 人民调解 → 行政调解 → 民事诉讼。诉讼外的协商/调解意见不当然约束法院，但可作为责任自认或和解基础审查。

## 病历与配套规范

| 规范 | 内容 | 适用场景 |
|------|------|----------|
| 《医疗机构病历管理规定》（2013年版） | 门（急）诊病历由医疗机构保管的，自最后一次就诊之日起不少于**15年**；住院病历不少于**30年** | 病历灭失责任与举证 |
| 最高法《关于审理医疗损害责任纠纷案件适用法律若干问题的解释》（法释〔2017〕20号，2020修正） | 患者主张病历伪造篡改申请过错推定的审查路径；医疗机构以患者不配合抗辩的举证责任；鉴定不能时按举证责任分配规则处理 | 病历攻防与鉴定不能 |
