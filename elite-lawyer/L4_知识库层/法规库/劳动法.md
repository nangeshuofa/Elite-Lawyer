# 法规库 · 劳动法分片

> 按 `index.md` 检索协议访问。本文件收录劳动合同法、劳动争议调解仲裁法、工伤保险条例等劳动领域高频条款。

## 劳动合同法（2012修正）— 订立与试用期

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第7条 | 用人单位自用工之日起即与劳动者建立劳动关系 | 劳动关系认定（不看合同看用工） |
| 第10条 | 建立劳动关系应订立书面劳动合同；已建立劳动关系未同时订立的，应自用工之日起1个月内订立 | 二倍工资计算起点 |
| 第14条 | 无固定期限劳动合同：连续工作满10年；连续订立2次固定期限合同后续订等，劳动者提出或同意续订的应订立 | 合同类型争议 |
| 第19条 | 试用期上限：合同期3个月-1年≤1个月；1-3年≤2个月；3年以上/无固定期限≤6个月；同一用人单位与同一劳动者只能约定一次试用期 | 试用期违法审查 |
| 第20条 | 试用期工资不低于本单位相同岗位最低档工资或劳动合同约定工资的80%，且不低于当地最低工资标准 | 工资追索 |
| 第26条 | 劳动合同无效情形：欺诈胁迫乘人之危；用人单位免除法定责任排除劳动者权利；违反法律强制性规定 | 合同效力争议 |

## 劳动合同法 — 解除、终止与补偿（核心攻防区）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第38条 | 劳动者被迫解除：未按约提供劳动保护/条件、未及时足额支付劳动报酬、未依法缴纳社保等，劳动者可解除 | 被迫解除+经济补偿（N）路径 |
| 第39条 | 用人单位过失性辞退：试用期不符合录用条件、严重违反规章制度、严重失职营私舞弊造成重大损害、被追究刑事责任等，解除不付费 | 解除合法性审查 |
| 第40条 | 无过失性辞退：医疗期满不能从事原工作及另行安排的工作；不能胜任经培训或调岗仍不能胜任；客观情况重大变化协商不成——提前30日书面通知或支付代通知金 | 解除程序合规 |
| 第41条 | 经济性裁员的法定情形与优先留用、程序要求（提前30日向工会或全体职工说明+报告劳动行政部门） | 裁员合规审查 |
| 第42条 | 不得依40/41条解除的情形：职业病危害作业未离岗前职业健康检查、疑似职业病；本单位患职业病或因工负伤丧失/部分丧失劳动能力；医疗期内；三期（孕期产期哺乳期）；连续工作满15年且距退休不足5年等 | 违法解除识别 |
| 第46条 | 应支付经济补偿的情形：38条被迫解除、40条、41条、44条第1项合同期满终止（单位不续或降低条件续订）等 | 补偿请求权基础 |
| 第47条 | 经济补偿按工作年限每满1年支付1个月工资；6个月以上不满1年按1年；不满6个月支付半个月。月工资高于当地上年度职工月平均工资3倍的，按3倍计算且年限最高不超过12年 | N的计算与封顶 |
| 第48条 | 违法解除或终止：劳动者要求继续履行的应继续履行；不要求或不能继续履行的，按第87条支付赔偿金 | 2N请求权基础 |
| 第50条 | 解除/终止时出具证明，15日内办理档案和社保关系转移 | 离职交接义务 |
| 第82条 | 用工超过1个月不满1年未订立书面劳动合同的，每月支付二倍工资 | 二倍工资主张 |
| 第85条 | 拖欠报酬/低于最低工资/不支付经济补偿等，劳动行政部门责令限期支付，逾期按应付金额50%-100%加付赔偿金 | 加付赔偿金（以行政程序前置为常态） |
| 第87条 | 违法解除或终止的，按经济补偿标准的二倍支付赔偿金（2N） | 违法解除索赔 |

## 劳动争议调解仲裁法

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第6条 | 与争议事项有关的证据属于用人单位掌握管理的（如考勤、工资表），用人单位不提供的承担不利后果 | 举证责任倒置攻防 |
| 第27条 | 仲裁时效1年，自知道或应当知道权利被侵害之日起算；拖欠劳动报酬争议，劳动关系存续期间不受1年限制，终止后应自终止之日起1年内提出 | 时效自查与抗辩 |
| 第43条 | 仲裁审理期限45日，案情复杂经批准可延长不超过15日 | 程序进度管理 |
| 第47条 | 一裁终局两类：追索劳动报酬、工伤医疗费、经济补偿或赔偿金不超过当地月最低工资标准12个月金额的争议；因执行国家劳动标准在工作时间、休息休假、社会保险等方面发生的争议 | 终局裁决识别 |
| 第48条 | 劳动者对一裁终局裁决不服的，可在15日内向法院起诉 | 劳动者救济 |
| 第49条 | 用人单位对一裁终局裁决，可向中级法院申请撤销（法定六情形） | 用人单位救济 |
| 第50条 | 非终局裁决：双方均可在15日内起诉；期满不起诉的发生法律效力 | 起诉期管理 |

## 工伤保险条例（2010修订）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第14条 | 应认定工伤七情形（工作时间+场所+原因；预备性收尾性工作；履职受暴力伤害；职业病；因工外出+下落不明；通勤非本人主责交通事故；法律法规其他） | 工伤认定申请 |
| 第15条 | 视同工伤：工作时间和岗位突发疾病死亡或48小时内经抢救无效死亡；抢险救灾等维护公共利益；因战因公负伤致残的复员转业军人旧伤复发 | 48小时条款攻防 |
| 第17条 | 时限：单位自事故伤害发生之日或诊断鉴定为职业病之日起30日内申请；单位未申请的，职工或近亲属、工会在**1年**内可直接申请 | 工伤认定时效（1年铁线） |
| 第33条 | 停工留薪期：原工资福利待遇不变，由所在单位按月支付；一般不超过12个月，伤情严重经鉴定委员会确认可延长不超过12个月 | 停工留薪争议 |
| 第37条 | 七至十级伤残待遇：一次性伤残补助金（十级7个月、九级9个月、八级11个月、七级13个月本人工资）+ 合同期满终止或本人提出解除时的一次性工伤医疗补助金（基金支付）与一次性伤残就业补助金（单位支付） | 伤残待遇清单 |
| 第39条 | 工亡待遇：丧葬补助金6个月统筹地区上年度职工月平均工资；供养亲属抚恤金；一次性工亡补助金为上一年度全国城镇居民人均可支配收入的**20倍** | 工亡索赔测算 |
| 第64条 | 本人工资：受伤前12个月平均月缴费工资；高于统筹地区职工平均工资300%的按300%计算，低于60%的按60%计算 | 待遇基数核定 |

## 劳动法（1995，基础条款）

| 条款 | 内容 | 适用场景 |
|------|------|----------|
| 第36条 | 每日工作不超过8小时、平均每周不超过44小时 | 工时合规 |
| 第44条 | 加班工资：延长工作时间150%；休息日安排工作又不能补休200%；法定休假日300% | 加班费追索 |
| 第50条 | 工资按月支付，不得克扣或无故拖欠 | 拖欠工资主张 |
