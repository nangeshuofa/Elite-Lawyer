# Elite-Lawyer 精英律师数字助手（公开版）

> 作者：楠哥说法
> 版本：V7.7.0（公开版）
> 协议：GPL-3.0

面向执业律师的数字助手技能，以案件为核心，提供文书生成、法律检索、合同审核、客户管理、时效预警、诉讼可视化、脑器交互合规、法律意见、伦理审查、品牌宣传、领导力（带团队/做决策/促共识）等全流程支持。

> **架构原则**：适应业务变化 · 支持持续演进 · 在稳定性/可维护性/可扩展性之间取得平衡（稳定性 > 可维护性 > 可扩展性）。
> **V7.x 理念**：合规不是刹车，是悬挂系统——审查与守门内建于流程，让执业跑得快且不散架。

## 关于公开版

本包是**面向不特定第三方分发的公开版**：已移除原使用者的个人化内容（姓名/律所/客户/案件标识）、第三方个人信息与机构标识，可直接安装使用；个人化信息在你的环境中由 `auto_profile` 机制自动回填。

| 项 | 公开版说明 |
|---|---|
| 个人化内容 | 全部移除，改由 `.state/config.json` + 对话自动回填；`lawyer_name` 等字段留空不阻塞任何功能 |
| 常识分片 | 民族/历史/哲学/社会学/政治学/音乐/艺术 7 片与地域专题 7 城**不在本包内**，见下方「可选加装包」 |
| 法条准确性 | 自 V7.6.6 起对法规库条文号做过原文核校勘误，明细见 `CHANGELOG.md` |
| 署名与许可 | 依 GPL-3.0 保留作者署名与仓库地址；包内随附 `LICENSE`（GPL-3.0 全文） |
| 自检 | 包内 `tools/check.py` 可离线自检，应输出 11 项 PASS、exit 0 |

## 快速开始

### 安装技能
`.skill` 文件本质是 ZIP，内含 `SKILL.md` 等文件于压缩包**根目录**。安装三步：
1. 解包 `elite-lawyer-public-v7.7.0.skill`
2. 放到技能根目录下，使路径为 `<技能根>/elite-lawyer/SKILL.md`（技能根因平台而异，常见为用户级 `~/.dsh/skills` 或项目级 `<项目>/.dsh/skills`）
3. 自检：`python3 tools/check.py <技能根>/elite-lawyer` —— 应为 11 项 PASS、exit 0

> 中文 Windows 提示：V7.6.5 及更早的 `check.py` 在 GBK 控制台打印 ✅ 会抛 `UnicodeEncodeError`；V7.6.6 起已修复。
> 技能目录若位于会话工作区之外，状态写入可能被平台沙箱拦截；此时按 `L0_存储层/存储契约.md` 的只读降级规则，状态暂存至会话工作区 `.elite-lawyer-state/`。

### 初始化配置
编辑 `.state/config.json`（或通过对话"设置我的律所为XX"），填入律师姓名、律所、默认法院、启用领域。
