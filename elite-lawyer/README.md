# Elite-Lawyer 精英律师数字助手

> 作者：楠哥说法
> 版本：V7.2.1
> 协议：GPL-3.0

楠哥专属的律师数字助手，以案件为核心，提供文书生成、法律检索、合同审核、客户管理、时效预警、诉讼可视化、脑器交互合规、法律意见、伦理审查、品牌宣传等全流程支持。

> **架构原则**：适应业务变化 · 支持持续演进 · 在稳定性/可维护性/可扩展性之间取得平衡（稳定性 > 可维护性 > 可扩展性）。
> **V7.x 理念**：合规不是刹车，是悬挂系统——审查与守门内建于流程，让执业跑得快且不散架。

## 系统架构（L0 治理面 + DA 四层执行栈）

```
L0 存储层 ── 状态持久化 + 架构约束 + 扩展点（模块注册表/领域配置/架构设计室/演进指南/集成接口）
    ↓
L1 内核层 ── 角色定位 + 执业原则（全局优先级唯一来源）+ 元认知（四步闭环）
    ↓
L2 机制层 ── 流程引擎 + 时效预警 + 知识发现 + 质控（可信度分级）+ 核准校验 + 边缘计算（纯规则）
    ↓
L3 模块层 ── 13 个功能模块（可扩展，M10 伦理审查为守门员）
    ↓
L4 知识库层 ── 法规库 + 案例库 + 模板库 + 裁判规则 + 执业规范 + 前沿领域 + 关系织网（按领域分片 + 读写协议）
```

## 快速开始

### 安装技能
下载 `elite-lawyer.skill` 文件，导入到你的 AI 助手平台即可使用。

### 初始化配置
编辑 `.state/config.json`（或通过对话"设置我的律所为XX"），填入律师姓名、律所、默认法院、启用领域。
