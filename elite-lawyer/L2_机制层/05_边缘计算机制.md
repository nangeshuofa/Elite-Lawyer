# 边缘计算机制 — 算力分流规则

> 核心价值：轻量运算、非重要运算下沉至边缘计算模型系统就近处理——提高响应速度、降低调用成本。重要运算与灰度决策仍回主模型。

## 一、机制说明

本机制是 L2 纯规则，被 L3 全部模块引用（V6.8 架构决策落入）。"边缘计算模型系统"指轻量级快速通道：模板填充、格式转换、简单查询等不承载法律判断的运算，走边缘就近处理；承载法律判断的运算一律回主模型。

## 二、分流原则

### 走边缘（轻量 / 非重要）
- 模板填充：套用既有模板替换变量（起诉状首部、律师函抬头）
- 格式转换：Markdown↔Word↔PDF、排版、字体字号调整
- 简单检索：已知位置的内容提取（在指定文件/卡片内查字段）
- 状态查询：`.state/` 读写、日程调取、待办清单、时效倒计时
- 文本清洗：转写纠错、去水印文字、段落重排

### 回主模型（重要 / 承载法律判断）
- 法律分析：定性、责任、构成要件、因果关系判断
- 文书起草：诉讼请求设计、事实与理由论证
- 合同审查：风险识别、条款谈判空间评估
- 灰度决策准备：选项生成与风险量化（拍板仍归决策人）

## 三、判定标准（唯一问句）

**该运算是否涉及法律判断或不可逆操作？**

- 否 → 边缘处理（快、省）
- 是 → 主模型处理（准、稳）
- 拿不准 → 按主模型处理（宁可慢，不可错）

## 四、与 L1 灰度决策边界的衔接

边缘计算只分流"算力"，不分流"判断权"。所有输出的最终审核仍适用输出可信度分级（✅/⚠️/❓）；边缘产出的中间件进入法律文书时必须经主模型复核标注可信度。机器算得出选项，算不出担责。

## 五、异常分支

- **边缘系统不可用 / 超时**：自动回退主模型执行，不阻塞任务，不向用户暴露内部通道细节
- **边缘输出被下游质疑**：该类运算规则本条记为"应走主模型"，下次分流时修正路由
- **成本与准确性冲突**：准确性压倒一切（设计哲学第二条），永远不为省钱牺牲法律准确性
