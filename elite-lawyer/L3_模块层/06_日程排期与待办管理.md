# 日程排期与待办管理模块 — 双轨联动的时间管理系统

> 核心价值：不漏事、不迟到、不错过时效。日程排期管"定人定时刻"的硬日程，待办管理管"无固定时刻"的任务池——既有区分，又有联动。（M06 由"日程提醒"升级而来；V7.0 自架构设计落地版并入）

## 一、双轨分工（既有区分）

### 轨道一：日程排期（硬日程）
- 管理对象：**定人、定时刻**的事项——开庭、值班、会议、面谈、立案截止、递交材料
- 执行规则：**到点执行，不顺延**。对应三层时间管理 V2.0 的 L1 硬日程
- 变更规则：硬日程改动必须显式确认（取消/改期需决策人拍板），不得静默顺延

### 轨道二：待办管理（任务池）
- 管理对象：**无固定时刻**的任务——跟进、文书、催收、回访、整理
- 执行规则：**未完成自动顺延次日**。对应三层时间管理 V2.0 的 L3 待办池
- 分类标签：按 SKILL.md「日程与待办分类体系」执行（六级待办 + 日程结构 + 心锚分类，2026-09-18 黄律师审定）——本模块只管双轨机制，不另设标签标准

> 事项分类的 P0-P3 标签与全局任务优先级（`L1_内核层/02_执业原则.md` 第五章）是不同维度，实际排序按全局优先级判定。

## 二、双轨联动（双向通道）

| 联动方向 | 规则 | 示例 |
|----------|------|------|
| 日程 → 待办 | 硬日程自动派生前置待办 | 开庭日程自动挂出「庭审提纲」「证据清单」前置任务 |
| 待办 → 日程 | 截止日临近的任务自动升格日程 | 「举证期限 7.10」待办在 7.8 自动升格为当日硬日程 |
| 每日滚动 | 每日待办 = 前日未完项滚动 + 当日日程派生项 | 昨日未完成的文书今天自动出现在待办首位 |

## 三、提醒机制（沿用并归入日程轨道）

### 多级提醒
| 事项类型 | 提前量 | 提醒方式 |
|----------|--------|----------|
| 开庭 | 7天、3天、1天、当天早上、出发前 | 飞书+日历 |
| P0时效 | 7天、3天、1天、当天 | 飞书+置顶待办 |
| 重要会议 | 3天、1天、1小时前 | 飞书提醒 |
| 常规事项 | 1天、当天 | 飞书提醒 |
| 客户回访 | 提前3天 | 待办清单 |

### 提醒内容标准
```
【开庭提醒】
📌 XX案 开庭
⏰ 时间：2026-XX-XX 09:00
📍 地点：XX法院 第X法庭
👤 经办法官：XXX
📋 准备清单（日程派生待办，自动生成）：
   □ 证据原件
   □ 庭审提纲
   □ 授权委托书
   □ 律师证
   □ 起诉状/答辩状
```

## 四、每日推送

### 早晨推送（07:30）
```
【今日安排】2026-07-08 周三

🔴 今日硬日程（到点执行）：
  09:00 XX案开庭（XX法院）
  14:00 客户XX面谈

🟡 今日待办（任务池，未完顺延）：
  □ XX案答辩状定稿
  □ XX合同审核
  □ XX案证据清单整理

⚡ 时效预警：
  ⚠️ XX案举证期还剩2天（7月10日截止）
```

### 晚间推送（20:30）
```
【今日复盘 + 明日预览】2026-07-08

✅ 硬日程完成：
  1. XX案开庭
  2. 客户XX面谈

🟡 待办完成 / 顺延：
  ✅ XX合同审核
  ➡️ 顺延明日：XX案答辩状定稿

📋 明日硬日程：
  09:00 XX法院递交材料
```

## 五、每周规划

### 周日晚/周一早推送
```
【本周规划】2026年第28周（7.8-7.14）

📅 硬日程：
  周三 09:00 XX案开庭
  周四 14:00 客户XX合同谈判
  周五 16:00 周复盘

⏰ 将升格为硬日程的待办：
  周四 XX案举证期截止（P0）

🎯 本周三大目标：
  1. XX案开庭顺利
  2. 完成XX案答辩+证据准备
  3. 拿下XX客户合同
```

## 六、待办录入方式

- 直接说"加个待办：XX事"（入任务池）
- 说"排个日程：周X XX点 XX事"（入硬日程轨道）
- 从案件/客户/合同中自动生成待办
- 时效类自动转化为待办，临近截止自动升格日程

## 七、状态落地

日程与待办变更写入 `.state/`（schedule.json / todo.json，结构遵循存储契约）；涉及时效的操作同步 `L2_机制层/02_时效预警机制.md` 的时效表。

## 八、使用方式

| 你说 | 我做 |
|------|------|
| "今天有什么安排" | 调出今日硬日程 + 待办池 |
| "本周有什么事" | 调出本周硬日程 + 待办 + 时效预警 |
| "排个日程：周四9点开会" | 写入硬日程轨道（到点执行） |
| "加个待办：XX案调证据" | 写入待办池（未完顺延） |
| "待办清单" | 调出任务池全量 + 顺延标记 |
| "XX案时效" | 调出该案所有时效节点 + 倒计时 |
| "帮我排一下今天的优先级" | 按全局优先级排序 + 建议 |

## 九、异常分支

- **信息不全**（只有"周四"没有时刻）：先入待办池并标注"待定时"，追问确认后升格硬日程
- **硬日程冲突**：两个硬日程撞时段，列冲突详情提请决策人取舍，不自动取舍
- **连续顺延 ≥3 天的待办**：标记为"僵持项"，检视该任务是否该做、该委托、该放弃，提请决策
