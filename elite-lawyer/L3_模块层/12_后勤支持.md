# 后勤支持模块 — 主战场的保障体系

> 核心价值：让楠哥把时间投给主战场（P0-P2），其余事务有人管、有章法、可追溯。（架构设计落地并入，M12）

## 一、模块说明

面向用户的保障入口，下辖五个子模块。与 L1 能量守恒法则直接衔接：可委托即委托、低杠杆事务批量处理。

- 定位：团队、健康、物资、环境的统筹管理
- 适用场景：团队成员/协作者事务、健康管理联动、物资调度、办公与家庭场景构建
- 不适用：案件本身的处理（走 M01）、日程排期（走 M06）、财务（走 M11）

## 二、五个子模块

### 1. 团队管理（偏对外）
- 管理对象：团队成员、外部协作者、人力资源
- 关系管理：对接人清单、协作偏好、跟进记录
- 适用：外部合作方联络、客户团队对接、行业协会事务

### 2. 组织管理（偏内部建设）
- 管理对象：队伍建设和团队内部关系
- 职责：分工明确化、协作流程沉淀、团队氛围与凝聚力
- 适用：内部协作规则制定、新人融入、团队例会与复盘

### 3. 健康管理
- 管理对象：楠哥及家庭成员的健康与运动
- 联动：与「法律人健康管理教练」技能联动（训练记录、体质追踪）；饮食合规走「食物合规检查」技能
- 数据：跑步法档案、体重血糖趋势、体检安排（细节见既有健康方案档案，本模块只做调度与提醒）

### 4. 物资管理
- 管理对象：物资调度与补给
- 范围：办公耗材、健康补给（钙/维D/鱼油等）、家庭常备物资
- 机制：补给品低于阈值生成补货待办（走 `06_日程排期与待办管理.md` 待办轨道）

### 5. 环境构建
- 管理对象：场景构建与场景秩序
- 范围：办公室仪式环境（更衣→红茶→经络按摩→进入状态）、家庭道场秩序（联动「道场维护群」）、出行场景准备
- 机制：场景秩序问题 → 记录 + 归因 + 建议，重要事项提请决策

## 三、统一执行规则

- 全部子模块的待办统一入 `06_日程排期与待办管理.md` 的待办池，不另立体系
- 涉及花钱的调度（采购/报销）联动 `11_财务管理.md`
- 涉及外部人员的沟通，先列草稿提请确认再发出

## 四、异常分支

- **子模块事务与主战场冲突**：按全局优先级（P0-P3）让位，低优先级事务降级为待办池
- **健康数据与技能档案不一致**：以技能侧最新档案为准，差异提请核对
- **物资/环境事务无决策依据**（如家庭采购分歧）：列选项 + 利弊，拍板权归决策人

## 五、使用方式

| 你说 | 我做 |
|------|------|
| "团队这块记一下：XX负责XX" | 入团队管理档案 |
| "该买XX了" | 入物资补货待办，联动财务 |
| "安排一下XX的体检" | 入健康管理待办，联动健康教练 |
| "办公室的XX坏了" | 入环境构建记录，给处理建议 |
| "后勤这块复盘一下" | 五个子模块逐项检视 |
