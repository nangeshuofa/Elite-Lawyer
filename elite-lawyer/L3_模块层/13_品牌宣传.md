# L3-13 品牌宣传（M13）

（V7.2 新增，2026-09-26 黄律师指令。定位：品牌资产管理 + 新媒体宣传全流程管理台。铁律：先过伦理审查，再谈流量——任何对外发布内容，发布前强制过 M10 宣传线。）

## 一、模块说明

- **知识底座**：`L4_知识库层/执业规范/执业伦理.md`（KM-007 业务推广禁令 / KM-008 新媒体宣传规范，V7.2 自动建立）
- **品牌主体**："楠哥说法"个人品牌（主阵地北京，直接遵循北京律协 2026-01 网络推广合规倡议书口径，参照浙江/广东/上海规范与平台公约）
- **四个子模块**：
  1. **品牌资产**：品牌定位口径库（一句话介绍/专业领域标签/**禁用词表**）、基础素材（账号简介/头像规范/模板），更新需律师确认
  2. **内容生产**：选题 → 大纲 → 成稿 → 事实核查（联动 M03 检索核实法条案例）→ **合规预审（强制联动 M10 宣传线）** → 排版（联动宿主 gzh-design 公众号排版能力）→ 发布
  3. **渠道运营**：公众号/抖音/小红书/视频号的平台规则差异维护（身份标示、内容边界、广告认定，见 KM-008）
  4. **数据复盘**：阅读/涨粉/转化记录，Markdown 表格直接回显（沿用 09-01 钦定偏好），不额外生成文档

## 二、合规红线（内置，发布前逐项过，全部有据可查）

① 不承诺办案结果、胜诉率、赔偿额、标的额（KM-007）；② 不用"最好/最专业/百分百解决"绝对化用语，不自称公认专家（KM-007/008）；③ 不明示暗示与办案机关等有特殊关系（KM-007）；④ 不贬低同行、不比较宣传（KM-007）；⑤ 推广内容标示姓名+执业证号+律所名称，荣誉称号注授予时间与机构（KM-007）；⑥ 虚构案例必须明确告知虚构性质（KM-008 浙江）；⑦ 在审案件不发表可能干预司法公正的评论（KM-008 浙江/北京）；⑧ 案例引用一律脱敏，不泄露当事人信息（KM-006）；⑨ 不做"卖惨/煽动对立/制造焦虑"噱头，不用 AI 拼凑不实信息（KM-008 北京/广东）；⑩ 标注"公益普法"不豁免广告属性（KM-008 上海）

## 三、交互式工作流

```
触发（"写一篇XX普法推文"/"公众号选题"/"内容排期"）
  ↓
内容线：选题 → 大纲确认 → 成稿 → 事实核查（法条/案例/数据逐一核） 
        → 合规预审（M10 宣传线，红线十项逐项过）→ 整改 → 排版 → 提请发布
运营线：口径/素材更新（律师确认后入库）→ 数据记录与复盘表格
  ↓
交付纪律：成稿+预审结论一起交；未过审的内容不进入发布队列
```

## 四、异常分支与降级

- **预审不过**：给整改选项（删承诺表述/补脱敏/改标题/换案例），整改后复审；两次不过改选题
- **平台规则变化**：核对平台最新公约（如抖音《社区法律行业公约》），变化处标 ⚠️ 提请人工确认；规范更新沉淀回 KM-008
- **涉及在审案件素材**：一律先提示 KM-008 干预司法红线，宁可不发
- **信息不全**：选题要素缺（受众/平台/目的）先追问，不硬写

## 五、使用方式

| 触发 | 输出 |
|------|------|
| "写一篇XX普法推文" / "公众号选题" | 成稿+合规预审结论（联动 M10） |
| "这个标题/文案能用吗" | 红线十项核查结论 |
| "品牌介绍更新一下" / "简介怎么写" | 口径库更新建议（律师确认后入库） |
| "下个月内容排期" / "上月涨粉数据" | 排期表 / 复盘表（Markdown） |

## 六、正反例（V7.1 教学法）

- ❌ **错误行为**："王律师胜诉率 90%，不赢不收费，关注我教你打赢官司"——承诺结果+宣示胜诉率+暗示兜底，命中 KM-007 第 10 条多项禁止，也是北京倡议书明确禁止的话术。错因：把线下广告禁令之外的话当成"新媒体新玩法"，行业规则对短视频直播同等适用
- ✅ **规范行为**："办理合同纠纷案件 XX 件（数据可核查），擅长建设工程合同审查——执业证号 XXXXXXXX，XX 律师事务所"——基于事实的专业陈述+完整身份标示，选题走"案例剖析/风险提示"形态并脱敏。**依据**：M13 红线十项 + KM-007 第 6 条 + KM-008 北京倡议书
